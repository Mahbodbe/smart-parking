### 📌 معرفی پروژه
پروژه **سامانه ابزار دقیق و اتوماسیون پارکینگ هوشمند** یک راهکار جامع اینترنت اشیاء (IoT) و سیستم جمع‌آوری داده (DAQ) است که به طور اختصاصی برای مدیریت مکانیزه و هوشمند پارکینگ‌های طبقاتی مدرن طراحی و پیاده‌سازی شده است. 

این سیستم فرآیندهایی نظیر جمع‌آوری داده از حسگرهای سخت‌افزاری مختلف (RFID، اولتراسونیک، اثر هال، دما و رطوبت، مادون قرمز)، کنترل حلقه-بسته زمان‌پیوسته بازوی گیت (کنترل‌کننده PID موتور سروو)، احراز هویت دو مرحله‌ای خودرو (تگ RFID + پردازش تصویر پلاک)، و ارسال تله‌متری آنلاین به داشبورد وب پایتون و ربات تلگرام را به طور یکپارچه اجرا می‌کند.

---

### 🚀 ویژگی‌های کلیدی سیستم

* **احراز هویت دو مرحله‌ای خودرو:** ایجاد لایه امنیتی دوگانه شامل اصالت‌سنجی تگ **RC522 13.56MHz RFID** و تطبیق همزمان پلاک و رنگ خودرو از طریق دوربین هوشمند ANPR.
* **تخصیص هوشمند نزدیک‌ترین جایگاه خالی:** کوئری بهینه و زمان‌حقیقی روی پایگاه داده بر اساس اولویت طبقه صعودی جهت کاهش مسافت پیمایش خودرو در طبقات:

$$\text{Target Slot} = \arg\min_{\{\text{floor, slot}\}} \{ \text{floor} \mid \text{Occupied} = 0 \}$$

* **معماری افزونگی چندلایه‌ای (Hardware Redundant):**
  * *تشخیص دوگانه حضور:* صحت‌سنجی متقاطع با حسگر اولتراسونیک HC-SR04 و حسگر مغناطیسی اثر هال A3144.
  * *پشتیبانی تغذیه:* سوئیچ سخت‌افزاری بدون وقفه بین برق شبکه شهری و باتری پشتیبان آنلاین (UPS).
  * *پایداری داده:* همگام‌سازی ابری با دیتابیس مرکزی همراه با بافرینگ محلی در حافظه EEPROM/SD کارت میکروکنترلر هنگام قطع ارتباط شبکه.
* **کنترل حلقه-بسته گیت (PID):** تنظیم دقیق پاسخ پله موتور سروو با فراجهش کمتر از ۵٪ ($\%OS < 5\%$) و زمان نشست زیر ۰.۳۲ ثانیه ($T_s < 0.32\text{s}$) به همراه سنسور مادون قرمز ایمنی ضدبرخورد (Anti-pinch).
* **داشبورد وب گرافیکی:** مانیتورینگ متمرکز شامل کارت‌های آمار زنده، نقشه گرافیکی وضعیت ۶۰ جایگاه اول، نمودارهای پویای Chart.js برای داده‌های محیطی و جدول لاگ ورود و خروج.
* **شبیه‌سازی همزمان در پروتئوس:** اتصال مستقیم محیط شبیه‌سازی Proteus به برد واقعی ESP32 از طریق پورت سریال مجازی (COMPIM) جهت تست زمان‌حقیقی مدار.

### ⚠️ تنظیمات اطلاعات وای‌فای و سرور روی ESP32

> [!IMPORTANT]
> **پیکربندی الزامی شبکه قبل از آپلود کد**  
> پیش از کامپایل و پروگرم کردن میکروکنترلر در پوشه‌های `arduinocode/` یا `rc522sevorgbwifi/`، **باید** اطلاعات دسترسی شبکه وای‌فای محلی و آدرس آی‌پی سرور پایتون خود را در فایل اصلی سورس‌کد (`.ino` / `.cpp`) تغییر دهید:
>
> ```cpp
> // اطلاعات شبکه خود را در این بخش جایگزین کنید:
> const char* ssid      = "نام_وای_فای_شما";
> const char* password  = "رمز_وای_فای_شما";
> const char* serverUrl = "http://YOUR_SERVER_IP:8000/api/gate/";
> ```
